Turnkey's transaction automation enables you to programmatically sign and submit transacti  ons across multiple blockchains with enterprise-grade security. Whether you're building a trading bot, a treasury management system, or an automated DeFi strategy, Turnkey provides the tools to sign transactions securely at scale.

## Key capabilities

- **Programmatic signing** — Sign transactions from your backend using API keys, with no manual intervention required.
- **Co-signing and approvals** — Enforce multi-party approval workflows before transactions are signed.
- **Policy engine** — Define granular rules that govern which transactions can be signed, by whom, and under what conditions.
- **Multi-chain support** — Sign transactions for Ethereum, Solana, Bitcoin, Cosmos, and many other networks.
- **Wallet import and export** — Bring existing keys into Turnkey or export them when needed.
