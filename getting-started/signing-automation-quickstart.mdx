  <Step title="Set up your environment" titleSize="h2">
    <AccordionGroup>
      <Accordion title="Create your account" defaultOpen="true" icon="id-badge" iconType="duotone">

        Navigate to the [Turnkey Dashboard](https://app.turnkey.com/dashboard/auth/initial) to create an account and set up your organization.

        Once logged in, open the user dropdown at the top right. Your Organization ID is listed there. Copy it for use in your code or environment variables.

      </Accordion>
      <Accordion title="Install the CLI" icon="terminal" iconType="duotone">

        Install the Turnkey CLI:

        ```bash
        brew install tkhq/tap/turnkey
        ```

        <Tip>For a more secure installation that avoids trusting external parties (here, Homebrew), see the [CLI repository](https://github.com/tkhq/tkcli).</Tip>

      </Accordion>
      <Accordion title="Install your preferred SDK (optional)" icon="code" iconType="duotone">

        You can use the CLI for the rest of this quickstart, or begin creating a more real-world integration by using your preferred SDK instead.

        <CodeGroup>

          ```javascript JavaScript

          ```

          ```python Python
          pip install turnkey-http turnkey-api-key-stamper
          ```

        </CodeGroup>

      <Accordion title="Store your Organization ID" icon="dollar-sign" iconType="duotone">

        Assign your Organization ID to the `ORGANIZATION_ID` environment variable. This is used to identify your organization in the following commands and API requests.

        ```bash
        export ORGANIZATION_ID=<YOUR_ORGANIZATION_ID>
        ```

      </Accordion>

      <Accordion title="Generate an API key" icon="key" iconType="duotone">

        You need an API key to authenticate Turnkey API requests.

        Create a new key named `quickstart` using the Turnkey CLI:

        ```bash wrap
        turnkey generate api-key --organization $ORGANIZATION_ID --key-name quickstart
        ```

        You'll see output like:

        ```json
        {
          "privateKeyFile": "/home/user/.config/turnkey/keys/quickstart.private",
          "publicKey": "03...72",
          "publicKeyFile": "/home/user/.config/turnkey/keys/quickstart.public"
        }
        ```

        The `quickstart` API key is used in every one of the remaining steps.

  <Step title="Sign a transaction" titleSize="h2">

    Now you can sign an Ethereum transaction with this new address using the [sign_transaction](/api-reference/signing/sign-transaction) API endpoint.

    Replace the `unsignedTransaction` value below with your own, actual transaction ID. If you need a quick transaction for testing, use Turnkey's [simple transaction generator](https://build.tx.xyz).

    <CodeGroup>

      ```bash CLI
      turnkey request --path /public/v1/submit/sign_transaction --body '{
          "timestampMs": "'"$(date +%s)"'000",
          "type": "ACTIVITY_TYPE_SIGN_TRANSACTION_V2",
          "organizationId": "'"$ORGANIZATION_ID"'",
          "parameters": {
            "type": "TRANSACTION_TYPE_ETHEREUM",
            "signWith": "<Your Ethereum address>",
            "unsignedTransaction": "<Your Transaction>"
          }
      }' --key-name quickstart
      ```
